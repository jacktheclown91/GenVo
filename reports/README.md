# Historical development and simulation evidence

This directory holds experimental outputs from previous GenVo8 passes, including logs, figures, test fixtures, observer replays and source comparison snapshots. These historical receipts have not been rewritten to reflect newer design policies, nor should their pass/fail outcomes be interpreted as universal endgame requirements.

For current direction, begin with `../docs/EMERGENT_EVOLUTION_AND_TEST_POLICY.md`, `../docs/TEST_INVENTORY_AND_POLICY.md` and `../docs/CANONICAL_SOURCE_AND_ART.md`. The current source of executable gameplay is `../src/`, not any archived source fixture nested in this directory. Preserve original receipts and clearly distinguish new reports from older fixed-seed hypotheses.

A later, separate archival pass may compact the large volume of generated reports once all dependent test fixtures, checksums, and external provenance links have been enumerated. This consolidation intentionally did **not** discard history just to make the ZIP smaller.
