## Size provenance

The current lineage authority retains conception body plans, genes and pigment, but omits parent bodySize. New S1 worlds therefore label those sizes unrecorded and disable inherited-size comparison. Living-parent size is never borrowed. The offspring's own recorded inherited adult length is disclosed separately. Default anatomy comparison normalizes inherited linear scale, with an explicit explanation; it no longer implies that unknown parent sizes are physically identical. Legacy worlds without size variation retain their reference-size interpretation.

The shared portrait adapter accepts owned, validated optional size data and uses it consistently for native bounds, paint and shadow. A physical-size view is available only when every displayed model has a retained size witness or belongs to a reference-size world. This prepares the reader for future authoritative witnesses; it does not create or backfill them. Claude's follow-up is recorded in PRESENTATION-COORDINATION-2026-10-28.md. Birth-card physical-size integration also remains open.
