## Required additions

1. **Evolutionary accessibility.** A catalog is not proof of possibility. Each major function needs an inherited path from a viable ancestor, reproducible legal mutations/recombination, viable intermediates in plausible conditions, material/energy costs and reproductive continuity. Include simplification. Record targeted experiment provenance; do not pretend every route must arise in an ordinary 100-day run. Current candidate/blocked routes are listed in `EVOLUTIONARY-ACCESSIBILITY.md`.
2. **Distinct planetary and detailed scales.** Global coarse geography owns continents, sea level, climate bands and macro watersheds at its own resolution and extent. Local pages sample/refine those coordinates. A 128/256-tile detailed window does not define planetary latitude or contain a compressed sample of every biome. Review the planet-scale mapping before increasing local extent. Current local climate remains a prototype that must not be advertised as this planet model.
3. **Capacity is not selection.** Current `spawnFundedOffspring` clips slots at maxAnimals. This is an unresolved biological validity defect, not an ecological limit. Before biodiversity/extinction interpretation, remove silent clipping or install explicit processing-capacity back-pressure that preserves pending funded births and reports lag rather than changing reproduction. Verify offspring count, maternal reserve accounting and deterministic resume at the former cap; never merely raise the cap. No population trial is authorized by A0/A, and none is being run.
4. **Observable consequences.** Every biological contract must name player/wildlife behavior, appearance, action/feedback and an inspected runtime demonstration: flight changes traversal/height/shadow; insulation changes body heat and actual exposure costs; a sensor changes information available. Genotype-only or decorative parts cannot pass a functional capability gate.
