October 17, 2026. This is an audit of an existing route, not implementation of new anatomy or completion of the evolutionary possibility space.

These counts describe this targeted two-founder fixture, not a natural-world emergence probability or required day100 outcome.

## Known violations and limits

This real reproduction route currently uses the background, non-player-lineage inheritance path. It bypasses the separate legacy lineage pressure-directed emergence path. The synthetic counterfactual in pressure-counterfactual.json proves that changing only exposure readout with identical parental state and initial RNG changes the lineage newborn. Its status is VIOLATED; successful diagnostic execution does not mean the biological requirement passed. Proto-speciation has another pressure-directed path identified by source audit, not yet independently runtime-tested.

The webbed-part projection also expresses water-sacs through a shared anatomy axis without a storage-sac part. This is a phenotype-authority conflict, not evidence of an inherited storage organ. Species-based body mass and incomplete tissue development mean anatomical material/maintenance costs remain unproven. The archived child has not yet survived to reproductive maturity and produced a viable descendant. Simplification, legless forms, flight, insulation and other catalog gaps remain open.

Consequently this is PARTIAL accessibility proof: real normal conception/gestation and a new inherited structural capability with inspected functional movement. It is not shared-rule player/autonomous acceptance, a mature lineage, or complete biological cost proof. NEUTRAL-INHERITANCE-REPAIR.md specifies the proposed repair before broader routes are approved. No runtime source changed, world expansion, major integrated100-day trial, commit, push or release was performed in this audit.
