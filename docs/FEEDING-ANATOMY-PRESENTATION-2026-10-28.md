# Anatomy-specific feeding expression

Implemented in the shared game renderer: mounted mouth capabilities now distinguish grazing, nibbling, pecking, crushing, tearing, filtering, suction and swallowing. A successful meal drives reach, processing and settle timing. Confirmed meals replace the redundant generic chewing clock; physiological cues remain. Tearing head motion combines with existing attention. Native mouth opening and small forward/transverse deformation follow the mouth's own axis in every direction; fixed-shape artwork retains its authored silhouette.

`feeding-expression.js` observes existing rich plant/water receipts, successful actor-stamped player actions (including carrion/canopy feeding), and the existing actor-owned `foraging.states.get(id).lastMeal`. It never calls the state-creating controller accessor. Rich same-tick tissue receipts retain seed fate and source attention. Movement, combat, work, flight, dormancy and anatomy replacement interrupt playback; an interrupted old meal does not replay. No food extraction, eligibility, nutrition, seed outcomes, original assets, save schema or simulation authority changed.

Runtime changes: `src/render/feeding-expression.js`, `behavior.js`, `part-sprites.js`, `renderer.js`. Native32 and optional64/128 share the same pose and transform path; gameplay size and artwork defaults are unchanged.
