# Direct E/Q interaction and resistant plant tissue

E now performs the current displayed interaction directly through the existing gameplay command, without opening a radial menu. Q cycles eligible nearby interactions, or the available actions on an explicitly mouse-selected object. The compact command label identifies the current choice. The selected action and exact world target remain bound until a new selection; if the action becomes invalid or its resource disappears, E explains rather than substituting unrelated food. New mouse selection resets keyboard intention. Actor/world changes release old intentions. Mouse radial interaction, Shift+E Drink, attack, defense, journal and mate-panel bindings remain available.

Keyboard selection is presentation-only in src/ui/quick-interaction.js. creature-context-tray.js supplies shared action descriptors and invokes existing playerInteract/approach routes; main.js routes Q to it. ForagingController clears its old manual-food selection only when Q explicitly begins cycling the broader interaction list. No second command execution system was introduced.

Continued gameplay development makes existing finite seed coats require paid handling. The authoritative harvest rejects unfunded opening and debits energy once for both manual and wildlife crop harvest. Mounted crush/peck capabilities reduce that effort. Wildlife search uses affordable net tissue return; ordinary soft-food feeding is unchanged, including starving creatures. Costs and invalid reasons feed the shared radial/dock/keyboard validators. Seed survival versus destruction, real litter, genotype cargo and resource accounting remain in the existing controllers. Manual feeding reactions last longer for costlier handling. Inspect exposes the coat and optional detailed effort information.

New plant-handling.js contains provisional constants: 16 energy per removed coat biomass, crush factor .25, peck factor .5. This uses the existing fixed inherited coat allocation; no new plant gene, defense mutation axis or sexual-reproduction rule was introduced. Quantities need balance testing; this is a functional protective-tissue slice, not a demonstrated evolutionary arms race.
