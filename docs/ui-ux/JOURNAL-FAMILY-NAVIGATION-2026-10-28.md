## Actual changes

1. **Family relationships are directly navigable.** Recorded parent and child creature portraits are now real labeled buttons. They open the family member's *existing* journal record instead of requiring cycling through unrelated records with Previous/Next. The record ID is taken from the existing lineage record, not generated by the UI.
2. **Life and family at a glance.** Above the family portrait layout, the Journal displays the existing birth/introduction record and counts of retained parents/children. No invented narrative, missing ancestor, inferred death cause, or extra simulation data is introduced.
3. **Reading and keyboard behavior.** Selecting a relative resets the old subject's scroll and focuses the new subject heading. Previous/Next still work and also start at the top of the next record, while retaining their own existing keyboard-focus behavior. Invalid/unretained record IDs do nothing. The Journal does not transfer player control; handoff remains its separate governed action.
4. **Readability.** Journal-only CSS increases small headings, notes, family captions, and navigation button label sizes, adds modest 44px footer controls, and makes kin portraits visually discoverable as interactive buttons. The at-a-glance facts stack on very narrow screens.

## Manual acceptance route

Start a genuine world with recorded family ancestry. Open Journal (L or menu), navigate to an offspring, then select a visible parent portrait with pointer and keyboard. The header should change to the parent's actual record without changing the controlled creature. Navigate into a child and back using the same portrait buttons. Use Previous/Next and the normal Close button. View long notes and optional parent/offspring comparison with both collapsed and expanded layouts. Repeat in a narrow browser and with historical family records where body detail is absent. Check that recorded counts and dates match the authoritative lineage data.

**Primary acceptance criterion:** a new player sees that creatures are related, can open a parent or child directly, and can find the difference between the current controlled creature and historical family records without deciphering a dense technical panel.
