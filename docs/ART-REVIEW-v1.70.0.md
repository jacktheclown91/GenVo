## Actual editor defect corrected

Canvas2D's `getImageData()` removes RGB beneath zero alpha. The native art source intentionally retains those bytes for canonical indexed identity, so even an untouched editor preview of an opened part could fail with `Indexed part: unmapped source color at 0`. `tools/creature-lab/native-frame-preservation.js` now recovers hidden RGB from the previously loaded exact RGBA frame (or the known source skin fallback on new fully transparent pixels). A real browser test opened `kick-spur`, selected its existing two-frame native sheet and installed its result into the temporary assembled-creature preview with no console errors. The preview does not modify the canonical asset until an explicit draft installation. The existing source-art installation workflow and all references were preserved.

The test harness uses an isolated page where secure WebCrypto may be unavailable. The canonical SHA-256 check now prefers WebCrypto and uses a byte-exact SHA-256 fallback in `src/render/sha256-bytes.js` only when `crypto.subtle` is absent. The fallback matches Node's SHA-256 across zero-length, padding-boundary and long vectors. It is not a fake checksum, and it does not change hash identity or provenance authority. The actual public game needs only compiled indexed assets, not client recompilation.

## Verification and limitations

Focused tests: native-part-catalog, native-specialty-wave (all 17 x eight facings x two frames, changed inherited skin and protected accents), native-sha256-fallback, native-lab-hidden-pixels, inherited pigment, anatomy rig/depth, assembled bodies, world slots, persistence and render-cache/pose tests. Real Chromium launched the game and assembled a 17-part, multi-direction, idle/moving review sheet: **78 native packs installed**, no browser exceptions, no missing assets, all legal body plans. Both source and public builds require separate real-world player acceptance; a headless screenshot is not equivalent to creator playtesting.

**Not finished or approved:** creature shapes still become visually repetitive, especially because chunky native limb sections dominate smaller complete bodies; some mobile/gameplay zoom facings and biological animation poses are not yet convincingly organic. Also remaining from earlier baselines: unrelated breeding/hydration and digging test defects, normal deployed save persistence, richer species-independent pattern/material variation. Catalog completion does not establish that every body part has expressive authored action animation; most currently have just two candidate idle frames. The older stable-release manifest remains unchanged deliberately.
