# Regional pressure observations — preparatory checkpoint

The ecological objective remains active. This checkpoint prepares actual,
bounded pressure records for regional comparisons; it does **not** complete
global related-population recognition or establish natural species emergence.
Normal new worlds still leave autonomous evolution off.

## Recorded policies

The explicit experimental `autonomousEvolution: true` constructor option now
selects `autonomous-evolution/3`. Published `/1` and `/2` strings retain their
recorded behavior and load without adoption. `/2` census headers retain `/2`;
the new code serializes each owner's actual policy rather than the latest one.

Only `/3` records the last two actually assessed pressure observations through
the existing population-memory daily controller. Each contains the biological
day and compact cumulative profile from that day. Reads return independent
copies. Missing days remain unknown: cumulative exposure is never subtracted
to invent prior observations. An actual current cumulative record can supply
its own day even when the optional buffer is absent.

Once this preparation checkpoint is published, `/3` itself is recorded behavior.
The later recognition-consumer change must use a new prospective policy (with
frozen `/3` controls) or an explicit backed-up adoption, rather than silently
changing existing `/3` saves. Recording observations does not opt a world into
future recognition rules.

Save restoration validates order, bounded length, owner identity, recorded
day/count, canonical pressure axes, finite ranges, ranking and the current
profile's agreement with actual cumulative memory. The helper is borrowed by
population memory and registered with that authority. It introduces no
population, ancestry, reproductive or species registry and consumes no RNG.

## Why record two days?

The canonical daily order records population memory, then evaluates speciation,
then increments the day. Regional work may legitimately straddle that boundary.
A future comparison can use the last fully co-observed biological day without
comparing different times or reconstructing missing history. This checkpoint
does not yet change reference selection or recognition's consumer timing.
