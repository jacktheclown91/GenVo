# Organic limb articulation development review

Mounted limbs previously alternated knee curl by socket-index parity, producing a pinwheel appearance. The shared pose now delegates knee construction to render/limb-articulation.js: knees bend behind the root/contact axis with mirrored lateral spread, rotate with facing, and flex with swing lift. Actual socket placement, organ count, contact cycle, native two-bone paint, anatomy gait factors and biology remain authoritative. No creature-specific poses or species dispatch were added.

Validation passed: limb-articulation (mirroring, facing rotation, immutable input points, finite geometry and support contact across 1024 walking poses), genvo-visual, motion-render, native-contact-expression-v174, physicality-render, player-motion-presentation, modular-head-v176. Canonical audit passed: 164 source modules, 161 runtime reachable, 79 native parts. Chromium loaded all native parts, captured normal/close world motion and enlarged actual seeded anatomy poses with no page errors. Species-label-only render invariance: 0 mismatched channels, 3199 opaque pixels. The browser capture did not observe wild bodies in this run (observedBodies 0); it is not new discovery coverage.

Natural quality remains partial: several bulky organ mounts still collide, upper/lower limb transitions can look angular, normal-zoom texture is limited, and silhouettes still reflect the current sparse founder anatomy.
