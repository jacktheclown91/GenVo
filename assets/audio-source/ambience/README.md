# GenVo environmental audio masters

Original deterministic, source-owned synthesis; no external recordings, models or music. Authoring: tools/generate_audio_assets.py. Codex-assisted environmental pass, 2026-10-23, under the creator's GenVo v1 direction.

Field, wet-ground and water-edge beds are nonvocal textures. Actual creature voices retain their existing anatomy/event authority. Rain is a separate stem driven by the current local liquid-precipitation reading; ground moisture never triggers rain by itself.

Each master is mono 16-bit PCM at 22050 Hz, exactly 12 seconds. The game ships Opus and AAC from assets/audio/ambience; masters remain toolkit-only. Scoped rebuild: python tools/generate_audio_assets.py --ambience-only. Unrelated voice/music/action masters and shipped files are preserved. Evidence and listening copies: docs/art-refinement-audio-v1-2026-10-23/README.md.
